# セキュリティ検証項目

コードを生成、拡張する際は、単なる「規約」としてではなく、「必須の検証項目」として以下のセキュリティ要件を満たしているか確認すること。

## 必須チェック項目 (OWASP ASVS準拠推奨)
1. **認証・認可 (Authentication & Authorization)**: 適切な認証フローの実装と、権限をオーバーライドできないことの検証。
2. **セッション管理 (Session Management)**: セッションハイジャック対策、トークンの適切なライフサイクル管理。
3. **入力値検証 (Input Validation)**: フロントエンドおよびバックエンドでの厳密なバリデーション（型チェック、長さ、ホワイトリスト）。
4. **出力エスケープ (Output Escaping)**: XSS対策のための出力時のサニタイズ。
5. **秘密情報管理 (Secrets Management)**: APIキー、パスワードのハードコード禁止、環境変数やSecret Managerの利用。
6. **ログの秘匿化 (Log Sanitization)**: PII（個人を特定できる情報）やパスワード、トークン情報をログに出力しないマスキング処理。
7. **ファイルアップロード制御 (File Upload Control)**: アップロードされるファイルの拡張子、サイズ、MIMEタイプの検証と、実行権限の排除。
8. **APIレート制限 (Rate Limiting)**: DoS攻撃防止のため、単位時間あたりのリクエスト数制限。
9. **テナント分離 (Tenant Isolation)**: マルチテナント環境において、別テナントのデータにアクセスできないDB設計とクエリ制御。
10. **管理画面保護 (Admin Interface Protection)**: IP制限や別経路でのアクセス、二要素認証(2FA)などの追加保護。
