# ダッシュボードUIテーマ構築仕様

SaaSとして様々な企業（テナント）にダッシュボードを提供するにあたり、ブランドカラーやロゴなどのUIテーマを安全にカスタマイズするためのルールです。

## 1. テーマの分離と管理 (`theme.py`)
- **ハードコードの禁止**: コンポーネントの色（`#FF5733`など）やフォントサイズを、各種スクリプトファイル（`app.py`, `utils.py`等）のインラインCSSとしてハードコードすることを固く禁じます。
- **一元管理**: すべてのデザイン要素（背景色、テキスト色、アクセントカラー、フォント）は、必ず `theme.py` などの独立したファイルで変数として定義し、そこからインポートして適用してください。

## 2. エンタープライズ向けカスタマイズの許容と制限
- **テナントごとのテーマ切替**: 企業Aと企業Bで異なるカラーテーマを提供できるよう、テーマ情報を辞書型やJSONで定義し、ログインテナントの情報に基づいて動的にロードできる仕組みを前提とします。
- **レスポンシブデザイン**: チャートやデータテーブルは、固定幅ではなくコンテナ幅をコンテキストに合わせる（`use_container_width=True` など）ことで、閲覧デバイスに応じた視認性を担保します。
- **アクセシビリティ (a11y)**: テキストと背景色のコントラスト比を適切に保ち、グラフの配色にはカラーブラインド（色覚多様性）に配慮したパレットを標準採用すること。
